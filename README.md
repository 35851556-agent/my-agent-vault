# My Agent Vault

这是我的 AI 私人档案库。每次跟 AI 助手对话时，让它先读这个仓库，就能快速进入状态。

## 目录结构

- `profile/` —— 我的画像、偏好、禁忌
- `knowledge/` —— 沉淀的知识笔记（股票、工具、生活）
- `prompts/` —— 好用的提示词模板
- `workflows/` —— 固定工作流
- `inbox/` —— 临时收集，定期整理

## 怎么用

1. 新对话开头先粘贴 `prompts/00-entry.md` 里的提示词
2. 让 AI 读这个仓库的 README、profile/user.md、profile/preferences.md
3. 对话结束后，让 AI 把重要内容整理成笔记存到对应目录
