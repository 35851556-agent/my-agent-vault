# 搭建 Agent 私人档案库（2026-10-20）

## 背景
想把 GitHub 作为 AI 助手的外置长期记忆，让每次对话不用重新交代背景。

## 最终方案
- 仓库：`my-agent-vault`（Private）
- 结构：profile/（画像）、knowledge/（笔记）、prompts/（提示词库）
- 接入方式：Personal Access Token（PAT），AI 通过 GitHub API 直接读写
- 入口提示词：`prompts/00-entry.md`，每次新对话先粘贴

## 今天做了什么
1. 确认 515070 是华夏中证人工智能 ETF（不是军工），完成当日复盘
2. 注册/登录 GitHub，创建私有仓库 my-agent-vault
3. 生成 PAT（repo 权限，90 天有效期）
4. 通过 API 批量写入 13 个文件：
   - profile/user.md、preferences.md、constraints.md
   - knowledge/stocks/2026-10-20.md（515070 日报摘要）
   - prompts/00 到 07 共 8 个提示词模板

## 关键决策
- 选 Private 仓库：投资记录、生活细节不公开
- 选 PAT 而非手动复制：以后存笔记直接让 AI 写入，不用手动操作
- 提示词按数字编号排序：00 是入口，后面按场景分类

## 下一步
- 每次新对话先粘贴 00-entry.md
- 对话结束后让 AI 整理笔记存到 knowledge/
- 好用的提示词用几次后微调，更新 prompts/ 目录
- 90 天后 token 过期，重新生成
